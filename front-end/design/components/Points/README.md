How many points a quest adds or takes away. The two kinds differ in three ways at once, so nobody relies on color: sign (`+` / `−`), fill (light `gain-soft` with `gain` text / solid `loss` with `on-loss` text), and lightness.

Use `.bq-points--gain` for positive and `.bq-points--loss` for negative. You provide the number; always write the sign, and use the real minus sign `−`, not a hyphen. No "pts" inside the pill.
